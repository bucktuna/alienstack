Radix

Linux install assistant

How it works

  1. Scan the target machine (coming: recommendations from your hardware)
  2. Pick a distro
  3. Download it from the official site
  4. Verify the checksum, here in your browser or with prep.py
  5. Flash it to a USB stick or SD card, outside the browser

Nothing you pick or hash here leaves this page. No tracking, no external scripts.

1 · Pick a distro

2 · Verify your download

Choose the image you downloaded. It is hashed locally in 4 MB slices, so even a 6 GB ISO is fine; it just takes a while (roughly a minute per GB on a typical laptop). The file is never uploaded.


    
Your browser can check the hash but not the GPG signature on the checksum
      file. For that run python3 prep.py fetch-sums <distro>.
      EndeavourOS publishes SHA-512 only: use prep.py verify --sums-file or sha512sum -c.

  


  

    
3 · Find your USB stick or SD card

    
    
      
  • Built-in SD slot: /dev/mmcblk0. USB stick or USB card reader: /dev/sdX.
    • 
      
  • Run lsblk before and after inserting it; the new disk is the one. Or sudo dmesg -w while inserting.
    • 
      
  • python3 prep.py drives -v lists only removable drives and says why others are hidden.
    • 
      
  • macOS: diskutil list external physical. Windows: Disk Management (diskmgmt.msc).
    • 
      
  • Check the size matches the label. A new cheap card? Test it with f3 for fake capacity.
    • 
    

  


  

    
4 · Flash it (outside the browser)

    
Web pages cannot write to USB drives: browsers block USB mass-storage devices on
      purpose. So the writing happens in a tool on your own computer.

    
Radix CLI (Linux)

    
python3 prep.py flash <image> --device /dev/sdX
# rehearsal only. To write, add:  --write --confirm <drive serial> --sums-file <sums>  (with sudo)

    
It refuses system disks, checks the image first, makes you type the drive's serial,
      then reads every byte back to confirm the write.

    
Or use a tool you already have

    
    
      
  • Linux: GNOME Disks → ⋮ → Restore Disk Image…, Raspberry Pi Imager, or balenaEtcher.
    • 
      
  • macOS: Raspberry Pi Imager or balenaEtcher.
    • 
      
  • Windows: Rufus, Raspberry Pi Imager or balenaEtcher.
    • 
    

    
Optional: pre-seed Wi-Fi (Raspberry Pi OS only)

    
Raspberry Pi OS reads a network config from the card on first boot, so Radix can add your
      Wi-Fi at flash time: --wifi-ssid NAME --wifi-psk-file FILE --wifi-country US.
      The password is read from a file or prompt, never typed on the command line. Generic live
      ISOs can't be pre-seeded.

    
If you used this tool to pre-program a Wi-Fi password, the password will
      remain on this machine, so don't give the machine away. The password is also stored in
      plain text on the USB/SD card's boot partition.

    
A one-click Radix Flasher helper is planned; it will keep the same rules.
