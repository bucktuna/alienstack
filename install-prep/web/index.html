Radix

Linux install assistant

How it works

  1. Scan the computer Linux will run on
  2. Pick a distro (the scan marks what fits) and download it
  3. Verify the download, here in your browser or with prep.py
  4. Find your USB stick or SD card
  5. Flash it, outside the browser

Nothing you scan, paste, pick or hash here leaves this page. No tracking, no external scripts.

1 · Scan the target machine

Run this on the computer you want to put Linux on: its current Linux, or a Linux live USB. It only reads system information (no sudo, nothing installed, nothing sent anywhere) and prints one line. It leaves out serial numbers, hostnames and network addresses.

1Copy & run this in a terminal
{ echo "arch=$(uname -m)"; c=$(LC_ALL=C lscpu 2>/dev/null | sed -n 's/^Model name:[[:space:]]*//p' | head -n1); [ -n "$c" ] || c=$(sed -n 's/^model name[[:space:]]*:[[:space:]]*//p' /proc/cpuinfo | head -n1); echo "cpu_model=$c"; echo "cores=$(getconf _NPROCESSORS_ONLN 2>/dev/null)"; echo "mem_kb=$(awk '/^MemTotal:/{print $2}' /proc/meminfo)"; s=unknown; if [ -d /sys/firmware/efi ]; then echo boot=uefi; case "$(mokutil --sb-state 2>/dev/null)" in *"SecureBoot enabled"*) s=enabled;; *"SecureBoot disabled"*) s=disabled;; esac; f=$(ls /sys/firmware/efi/efivars/SecureBoot-* 2>/dev/null | head -n1); if [ "$s" = unknown ] && [ -n "$f" ]; then case "$(od -An -tu1 -j4 -N1 "$f" 2>/dev/null | tr -d ' ')" in 1) s=enabled;; 0) s=disabled;; esac; fi; else echo boot=bios; s=not-applicable; fi; echo "secure_boot=$s"; for k in vendor version date; do echo "fw_$k=$(cat /sys/class/dmi/id/bios_$k 2>/dev/null)"; done; echo "board=$(tr -d '\000' 2>/dev/null < /proc/device-tree/model)"; echo "disk_bytes=$(lsblk -dbno SIZE,TYPE 2>/dev/null | awk '$2=="disk" && $1>m {m=$1} END {print m+0}')"; lspci 2>/dev/null | sed -n -e 's/^[^ ]* VGA compatible controller: /gpu=/p' -e 's/^[^ ]* 3D controller: /gpu=/p' -e 's/^[^ ]* Display controller: /gpu=/p' -e 's/^[^ ]* Network controller: /wifi=/p'; } | base64 | tr -d '\n' | sed 's/^/RADIX-SCAN-1:/'; echo
2Paste the result (the line starting RADIX-SCAN-1:)

Your machine

How each distro fits

    Rules use only facts confirmed on official pages (architecture, documented RAM minimums, official Secure Boot support). Anything Radix can't confirm stays unknown.

    Other ways to scan
    • With Radix downloaded: python3 prep.py scan (summary) or python3 prep.py scan --paste (the same one line; --json also works here).
    • Windows: msinfo32 shows System Type (x64/ARM64), Installed Physical Memory, BIOS Mode (UEFI/Legacy), Secure Boot State and BIOS Version. Fill in step 2 by running the command above from a Linux live USB instead, or just pick using those values.
    • macOS: Apple menu → About This Mac (chip, memory). Intel Macs can boot many x86_64 distros; Apple Silicon Macs need Asahi Linux, which is not in this catalog.

    An estimate, this device only: browsers can't see Secure Boot, firmware or boot mode, and report memory only approximately (capped at 8 GB). Unknown stays unknown.

    2 · Pick a distro

    3 · Verify your download

    Choose the image you downloaded. It is hashed locally in 4 MB slices, so even a 6 GB ISO is fine; it just takes a while (roughly a minute per GB on a typical laptop). The file is never uploaded.

    
    
    Your browser can check the hash but not the GPG signature on the checksum
      file. For that run python3 prep.py fetch-sums <distro>.
      EndeavourOS publishes SHA-512 only: use prep.py verify --sums-file or sha512sum -c.
    
  
    

  
    
    
    4 · Find your USB stick or SD card
    
    
      
      
    • Built-in SD slot: /dev/mmcblk0. USB stick or USB card reader: /dev/sdX.
      • 
      
    • Run lsblk before and after inserting it; the new disk is the one. Or sudo dmesg -w while inserting.
      • 
      
    • python3 prep.py drives -v lists only removable drives and says why others are hidden.
      • 
      
    • macOS: diskutil list external physical. Windows: Disk Management (diskmgmt.msc).
      • 
      
    • Check the size matches the label. A new cheap card? Test it with f3 for fake capacity.
      • 
    
    
  
    

  
    
    
    5 · Flash it (outside the browser)
    
    
    Web pages cannot write to USB drives: browsers block USB mass-storage devices on
      purpose. So the writing happens in a tool on your own computer.
    
    
    Radix CLI (Linux)
    
    
    python3 prep.py flash <image> --device /dev/sdX
# rehearsal only. To write, add:  --write --confirm <drive serial> --sums-file <sums>  (with sudo)
    
    
    It refuses system disks, checks the image first, makes you type the drive's serial,
      then reads every byte back to confirm the write.
    
    
    Or use a tool you already have
    
    
      
      
    • Linux: GNOME Disks → ⋮ → Restore Disk Image…, Raspberry Pi Imager, or balenaEtcher.
      • 
      
    • macOS: Raspberry Pi Imager or balenaEtcher.
      • 
      
    • Windows: Rufus, Raspberry Pi Imager or balenaEtcher.
      • 
    
    
    
    Optional: pre-seed Wi-Fi (Raspberry Pi OS only)
    
    
    Raspberry Pi OS reads a network config from the card on first boot, so Radix can add your
      Wi-Fi at flash time: --wifi-ssid NAME --wifi-psk-file FILE --wifi-country US.
      The password is read from a file or prompt, never typed on the command line. Generic live
      ISOs can't be pre-seeded.
    
    
    If you used this tool to pre-program a Wi-Fi password, the password will
      remain on this machine, so don't give the machine away. The password is also stored in
      plain text on the USB/SD card's boot partition.
    
    
    A one-click Radix Flasher helper is planned; it will keep the same rules.
